# 🟨 5. Moteur de classification

### 📝 Description

Implémenter un moteur de classification multi-niveaux basé sur NLP + RAG.

### 📊 Données

* tickets ITSM
* documentation enrichie
* incidents similaires

### 🎯 Fonctionnalités

* type de ticket (incident / demande)
* domaine technique
* sous-catégorie

### 🎯 Objectif

Structurer automatiquement les tickets entrants.
