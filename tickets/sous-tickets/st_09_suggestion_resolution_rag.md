# 🟨 9. Suggestion de résolution (RAG)

### 📝 Description

Générer des recommandations de résolution basées sur incidents historiques et documentation.

### 🛠️ Outils

* ITSM (historique incidents)
* Confluence (runbooks)
* Monitoring (signaux système)
* CMDB (dépendances)

### 📊 Données

* incidents similaires
* runbooks techniques
* post-mortems
* métriques systèmes

### 🎯 Objectif

Fournir des actions concrètes et actionnables pour résolution rapide.
