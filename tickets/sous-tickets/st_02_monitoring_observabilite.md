# 🟨 2. Intégration Monitoring & Observabilité

### 📝 Description

Connecter les outils de monitoring pour enrichir les tickets avec des signaux techniques en temps réel.

### 🛠️ Outils

* Datadog
* Prometheus
* Grafana

### 📊 Données

* métriques système (CPU, latence, erreurs)
* alertes actives
* logs applicatifs

### 🎯 Objectif

Corréler tickets utilisateurs et incidents techniques réels.
